# don't hmm

구글시트를 DB로 쓰는 카운터 웹페이지예요. (Next.js 15 + Tailwind, Vercel 배포)
상단에서 사용자(나)를 고르면 내 시트의 행위자별 행동 버튼이 나오고, 누를 때마다 카운트가 올라가요.

## 1. 구글시트 만들기

- **시트 탭 1개 = 사용자 1명**이에요. 탭 이름이 화면 상단의 사용자 이름이 돼요.
- **사용자**는 이 사이트를 쓰는 사람, **행위자**는 카운팅 당하는 사람이에요.
- 각 탭의 1행에 헤더를 이렇게 넣어주세요. (순서는 상관없어요)

예) `김대리` 탭

| 순번 | 행위자 | 행위명 | 카운트 |
| ---- | ------ | ------ | ------ |
| 1 | 김과장 | 회의 중 다리떨기 | 0 |
| 2 | 김과장 | 슬랙 읽씹 | 0 |
| 3 | 박대리 | 점심 먹고 낮잠 | 0 |

- 사용자를 추가하려면 탭을 새로 만들고 1행에 헤더를 넣으면 돼요. (최대 15초 뒤 상단에 나타나요)
- 탭 이름이 `_`로 시작하거나 숨긴 탭, 비어 있는 탭은 사용자로 안 보여요. 기본으로 있는 빈 `시트1` 탭은 지우거나 이름을 바꿔주세요.
- 화면에서는 행위자별로 묶여서 버튼이 나와요. 행을 추가하면 버튼이 자동으로 생겨요.
- **순번**은 같은 탭 안에서 겹치지 않게 넣어주세요.
- Apps Script 편집기에서 `setup` 함수를 한 번 실행하면 `사용자1` 예시 탭이 만들어져요.

## 2. Apps Script 배포

1. 시트에서 **확장 프로그램 → Apps Script** 를 열고 `apps-script/Code.gs` 내용을 붙여넣어요.
2. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
3. 나온 웹 앱 URL(`…/exec`)을 복사해둬요.

> 코드를 고친 뒤에는 **배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영돼요.

## 3. 로컬에서 실행

```bash
npm install
cp .env.example .env.local   # 열어서 NEXT_PUBLIC_SHEET_API_URL 에 URL 붙여넣기
npm run dev                  # http://localhost:3000
```

## 4. Vercel 배포

1. 이 폴더를 GitHub에 올려요.
2. Vercel에서 **Add New → Project** 로 해당 저장소를 가져와요.
3. **Environment Variables** 에 `NEXT_PUBLIC_SHEET_API_URL` = 위에서 복사한 URL 을 등록해요.
4. Deploy!

## 문구 / 이모지 바꾸기

`src/config.ts` 에서 제목, 안내 문구, 팝업 이모지 목록, 새로고침 주기를 바꿀 수 있어요.

## 참고

- 접속하는 누구나 버튼을 누를 수 있어요. (로그인 없음) 사내 공유용으로 링크만 돌리는 용도예요.
- 링크 끝에 `#/김대리` 처럼 사용자 탭 이름을 붙이면 그 사용자 화면으로 바로 열려요.
